# Koinos Node Manager Agent Instructions

## Language Policy

The user may communicate with Codex in Spanish or another language, but every
artifact created or modified in this repository must be written in English.

This rule applies without exception to:

- source code and identifiers;
- inline comments and docstrings;
- documentation and implementation plans;
- user manuals and developer guides;
- architecture decision records;
- UI labels, descriptions, dialogs, status messages, and error messages;
- CLI commands, help text, prompts, progress messages, and output;
- tests, fixtures, snapshots, and test descriptions;
- configuration examples and templates;
- changelog and release notes;
- commit messages, branch descriptions, and pull-request content.

Conversation with the user may remain in the user's preferred language. Do not
copy Spanish discussion text into repository artifacts. Translate the intended
meaning into clear, idiomatic technical English before writing it.

When localization is implemented, English remains the source language in the
repository. Translations may be added only through the project's localization
system and must not create mixed-language source copy.
